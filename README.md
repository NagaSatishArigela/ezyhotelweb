# EzyHotels.com — Coming Soon

Static "Opening Soon" landing page for **ezyhotels.com**, hosted on GitHub Pages.

- `index.html` — the page (self-contained, responsive)
- `ezyhotels-logo.png` / `ezyhotels-mark.png` / `favicon.png` — brand assets
- `CNAME` — custom domain for GitHub Pages (ezyhotels.com)

## Deploy
1. Push to a GitHub repo (branch `main`).
2. Repo → Settings → Pages → Source: "Deploy from a branch" → `main` / root.
3. Set custom domain `ezyhotels.com`, then enable "Enforce HTTPS".
4. Point GoDaddy DNS at GitHub Pages (see the deploy notes).

Replace the `#` social links in `index.html` footer with real profile URLs when ready.
